Definition:
BS is your custom Bible study framework that combines Bible reading + language learning + vocabulary analysis + grammar reinforcement using multiple translations (English, Portuguese ARC, and German). It is designed to strengthen both scripture comprehension and language acquisition in a consistent repeatable structure.

Purpose

BS is used to:

Study the Bible chapter-by-chapter
Learn Portuguese and German alongside English
Build vocabulary from actual Bible text
Observe grammar patterns naturally in context
Preserve consistency across daily studies
Create a reusable study archive
Standard BS Structure
Brief Summary (placed at top)
Short chapter overview
Based on chapter content
No extensive commentary
Nouns
Currently 10 words
Chapter-derived
Preserved in chapter order
Includes language translations and grammar information
Adjectives
Currently 10 words
Verbs
Currently 10 words
Adverbs
Currently 10 words
If naturally limited in chapter, use valid chapter expressions
Grammar Lesson (placed at end)
Portuguese: 2 short technical grammar notes
German: 2 short technical grammar notes
Table Structure

Current standard form:

| English | Portuguese (ARC) | German | Grammar Info | Column 5 |

Column 5 Rule:

Dynamic language column
May be Portuguese, German, or another requested language
Uses a chapter-related phrase fragment/example
Language specified by the command

Examples:

BS Numbers 19 with portugues in col 5
BS John 3 with german in col 5
Example Commands
BS Numbers 19 with portugues in col 5
BS Exodus 20 with german in col 5
BS John 3
Goal

Read Scripture → Extract vocabulary → Observe language patterns → Reinforce grammar → Build long-term language ability

This effectively turns Bible reading into a multilingual structured study system rather than only a devotional reading.
=======
You can use this standardized prompt format for all future Bible Study requests.

---

# Standard Prompt

```text
BS <Book Chapter> with Portuguese in column 5
```

Example:

```text
BS 1 Corinthians 12 with Portuguese in column 5
```

---

# Definition of the BS Format

The response must contain:

## 1. Summary at the Top

A concise summary of the chapter or passage.

---

## 2. Vocabulary Tables

Create separate tables for:

* Nouns
* Adjectives
* Verbs
* Adverbs

Use exactly 10 entries when available from the passage.

Maintain the order of first appearance in the chapter.

Do not invent filler words.

---

# Required Table Format

| English | Portuguese | German | Verse | Portuguese Fragment Text |
| ------- | ---------- | ------ | ----- | ------------------------ |

### Column Definitions

| Column                   | Definition                                                              |
| ------------------------ | ----------------------------------------------------------------------- |
| English                  | English word from the verse                                             |
| Portuguese               | Portuguese translation                                                  |
| German                   | German translation                                                      |
| Verse                    | Verse reference where the word appears                                  |
| Portuguese Fragment Text | Actual Portuguese ARC-style fragment from the verse containing the word |

---

# Additional Rules

* Use ARC-style Portuguese wording in Column 5.
* Preserve biblical context.
* Avoid proper nouns unless meaningful to the study.
* If fewer than 10 true examples exist, do not fabricate entries.
* Keep vocabulary tied directly to the passage.
* Maintain order of appearance in the text.

---

# 3. Grammar Lessons at Bottom

Include:

## Portuguese Grammar Lesson

Using vocabulary/examples from the chapter.

## German Grammar Lesson

Using vocabulary/examples from the chapter.

---

# Example Prompt

```text
BS Numbers 29 with Portuguese in column 5
```

or

```text
BS 1 Corinthians 12 with Portuguese in column 5
```


All vocabulary categories (Nouns, Adjectives, Verbs, Adverbs) must be listed in order of first appearance in the chapter text.
